The modern tooling stack keeps asking for signups. My favorite tools don't.

## Qualities of Small Tools

- Config as a single file
- Exit code reliability
- Also: no dashboard, no workspace, no seat pricing

## My Current Kit

```text
rg     search
jq     reshape
curl   probe
wr     measure
```

## Make Your Own When Cheap

A 40-line script beats a 400-line dependency when the job stays small.

> Big tools win demos. Small tools win weeks.
